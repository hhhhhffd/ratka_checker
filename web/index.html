RatScan

Статический анализатор .jar модов Minecraft: ищет стилеры токенов, загрузчики, RAT и эксфильтрацию через вебхуки — разбирая байткод, а не запуская его.

Скан идёт локально в WebAssembly — файл не покидает ваш компьютер.

/100 риск

Статический анализ не гарантирует безопасность: clean значит «опасных цепочек не найдено», а не «проверено вручную».

Исходный код на GitHub · Rust → WebAssembly
